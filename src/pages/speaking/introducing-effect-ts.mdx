# Introducing EffectTS
##### February 6, 2025 | [DK&A's Office](https://dka.io/)
##### February 13, 2025 | [Wrocław TypeScript](https://github.com/WrocTypeScript/)
---

- 📊 **Demo**: https://github.com/kajetansw/effect-ts-demo
- 👨‍💻 **Form**: talk + live coding

---

This talk served to introduce the audience to the next-gen solution for functional programming in TypeScript - [EffectTS](https://effect.website/). This in-depth introduction covered: the `Effect` type, how to create Effects, how to compose Effects (pipes and generators), example on how to translate existing API to Effect domain, example of useful utils.

Coming from [fp-ts](https://effect.website/docs/additional-resources/effect-vs-fp-ts/) or other functional programming libraries? You'll definitely find something interesting diving into EffectTS!
